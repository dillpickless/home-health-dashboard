# Home Health Dashboard

A personal, non-commercial dashboard that reads one household's own Oura Ring data through the Oura API v2 and displays it locally.

- Single household use. Not offered to the public.
- Data is pulled over OAuth2 with the ring owner's explicit consent.
- Data is stored on a private computer and is not shared with anyone.

See [PRIVACY.md](PRIVACY.md) and [TERMS.md](TERMS.md).
